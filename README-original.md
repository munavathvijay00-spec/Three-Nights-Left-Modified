## About the Game

**Three Nights Left — Modified** is a Unity survival game project based on the original open-source game *Nightfall*.

The player has one mission: **survive three increasingly dangerous nights**.

During the day, gather resources, craft equipment, prepare defenses, and manage hunger. At night, defend against waves of hostile creatures.

Every decision matters. Every resource counts. Every night becomes harder.

## Gameplay — The Three-Night Challenge

### Day (06:00–20:00)

The world is relatively safe. Explore, chop trees, mine stone and iron, dig for loot, craft weapons, cook food, repair turrets, and trade with the shopkeeper.

### Dusk

The sunlight fades. This is your final warning to return to safety, prepare your weapons, and reinforce your defenses.

### Night (20:00–06:00)

Enemies emerge and close in. Fight with rifles and melee weapons while your defensive turrets hold the line. Each night introduces greater danger.

### Dawn

Sunlight drives the monsters away. Rebuild, recover, and prepare for the next attack.

**Survive all three nights to win.**

## Game Features

- **Dynamic Day/Night Cycle:** A continuously advancing clock, realistic lighting transitions, and changing background music.
- **Resource Gathering:** Chop trees, mine stone and iron, dig for loot, and repair structures.
- **Inventory and Crafting:** Collect resources, craft tools and weapons, and cook food.
- **Survival Mechanics:** Monitor health and hunger while managing limited supplies.
- **Combat System:** Use rifles, reloading, melee attacks, and enemy-targeted movement.
- **Defensive Turrets:** Automatic enemy tracking and shooting, with ammunition replenished through repairs.
- **Five Enemy Types:** Zombie, Ghoul, Girl Scout, Mutant, and Parasite.
- **Escalating Enemy Waves:** Increasing spawn rates, enemy density, and difficulty across the three nights.
- **Wildlife:** Chickens and cows that roam the environment and provide resources.
- **Isometric Camera:** Follow camera with mouse-wheel zoom.

These are features documented for the original game. Their functionality in the modified version still requires complete testing.

## Game Controls

| Input | Action |
|---|---|
| WASD / Arrow Keys | Move character |
| Mouse Wheel | Zoom camera |
| Left-click highlighted object | Move to and interact with object |
| Left-click elsewhere | Aim and fire rifle, if equipped |
| E | Interact with nearest object |
| R | Reload weapon |
| V | Melee attack |
| Right-click enemy | Approach and melee attack |

Keyboard and mouse are the primary controls. Some movement and interaction actions also support gamepads.

## Getting Started

1. Install Unity Editor **6000.5.1f1** through Unity Hub.
2. Install Git LFS.
3. Clone the repository:

```bash
git lfs install
git clone https://github.com/munavathvijay00-spec/Three-Nights-Left-Modified.git
```

4. Open the downloaded project in Unity Hub.
5. Open the appropriate game scene from `Assets/Scenes`.
6. Press **Play** to test.

**Note:** Complete gameplay and standalone macOS compatibility have not yet been verified.
